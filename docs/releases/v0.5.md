- One window for Windows, Linux and macOS (Avalonia + OpenGL); every tool runs in a window-free editor layer.
- MCP server: an AI assistant can work along in the open window when "AI assistant may work along" is ticked (draw, push/pull, revolve, follow me, groups, screenshots); every change can be undone.
- Free-form faces, STEP as the main format, a structure tree with renaming, and a join toggle.
- A mesh opens in the converter's own window first.
